## Featured projects

### Lirkod

A Hebrew-first platform for Israel's folk-dancing community, built with Next.js, React, TypeScript, Supabase, PostgreSQL, and PostGIS.

Engineering highlights include spatial proximity queries, recurring-event materialization, phone OTP authentication, role-based interfaces, Row Level Security, and dedicated unit, end-to-end, and database authorization tests.

### Royal Frame

A cross-platform Flutter card game for Android and the web, with Firebase authentication, persistent progression, online leaderboards, and real-time 1v1 duels.

The project separates game rules from UI code and includes transaction-based score updates, localization, secure local storage, Firebase App Check, and Flutter unit and widget tests.
